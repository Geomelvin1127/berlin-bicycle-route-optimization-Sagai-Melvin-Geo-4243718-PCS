🚴‍♂️ Berlin Bicycle Delivery Route Optimisation

A graph-based routing engine using Dijkstra, A*, and multi-stop heuristics — now upgraded with real Berlin street networks and an interactive web app.

🌍 Project Overview

Urban bicycle couriers face complex routing challenges:
multiple stops, dynamic traffic, long distances, and efficiency pressure.

This project demonstrates how computational methods, algorithms, and geospatial data can optimise multi-stop bicycle delivery routes in Berlin.

The system includes:

- Weighted graph modelling
- Dijkstra & A* shortest path algorithms
- Multi-stop nearest-neighbour route optimisation
- Real Berlin map support (OSMnx)
- Edge-usage simulation (heatmap)
- Streamlit web application
- Visualisation + animation
- Runtime analysis (performance benchmarking)
